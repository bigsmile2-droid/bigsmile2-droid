# Cisco Networking and Security Lab Project

## OVERVIEW
This project presents the design,confirguration,and stimulation of a secure,enterprise grade network infrastructure built within cisco packet tracer.developed in alignment with methodologies from the Cisco Networking Academy,this project serves as a pratical blueprintfor deploying core network serevices and robust security layers.
The architecture demonstrates the end to end traversal of data across the TCP/IP stack,showcasing the orchestration of crucial application layer protocols (HTTP,HTTPS,DNS) alongside cryptographic standards(SSL,TLS) to protect data in transit against interceptive threats.

## Project objectives
End to end simulation:Architect a functional multi-subnet network topology mirroringa real-world corporate environment.
Protocol analysis:inspect granular data packet behaviour,tracking TCP handshakes and encryption exchanges to ensure archtectural integrity.
